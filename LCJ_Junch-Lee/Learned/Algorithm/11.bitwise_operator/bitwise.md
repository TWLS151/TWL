# 비트 연산 (with 진수 Number System)

### 2진수, 16진수의 표현

2진수 : `0b`를 접두사로 붙여 표현

- ex. `0b1010` : 10진수 `10`

16진수 : `0x`를 접두사로 붙여 표현

- ex. `0xa` : 10진수 `10`

`print` 문을 활용

```py
print(int('1011', 2)) # 11

print(int('b', 16)) # 11
```

### 1. AND(`&`) 와 OR(`|`) 연산

- `AND` : 각 자리수에 대해, 둘 다 `1` 이면 `1`

- `OR` : 둘 중 하나만 `1` 이어도 `1`

```py
print(7 & 5) # 5

print(7 | 5) # 7
```

### 2. XOR (`^`) 연산 : 연산자, 둘 다 1이거나 0인 경우는 0

```py
a = bin(0b1011 ^ 0b1101)

print(a) # 0b110
```
