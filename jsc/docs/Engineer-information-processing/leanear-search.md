# Linear Search (선형 검색)의 특징 및 오해 정리

## 1. 선형 검색의 정의
* **선형 검색(Linear Search)** 또는 **순차 검색(Sequential Search)**은 리스트의 처음부터 끝까지 차례대로 각 요소를 대상 값과 비교하여 원하는 항목을 찾는 알고리즘입니다.

## 2. 주요 특징
* **정렬 여부:** 데이터가 **정렬되어 있지 않아도** 검색이 가능합니다. (가장 큰 장점 중 하나)
* **시간 복잡도:** $O(n)$ - 최악의 경우 모든 요소를 다 확인해야 합니다.
* **구현:** 매우 단순하며 직관적입니다.

## 3. 틀린 설명 바로잡기 (문제 관련)
* **잘못된 설명:** "선형 검색은 검색을 수행하기 전에 반드시 데이터의 집합이 정렬되어 있어야 한다." (X)
* **옳은 설명:** * 선형 검색은 정렬되지 않은 데이터에서도 문제없이 동작합니다.
    * 검색 전 반드시 데이터가 정렬되어 있어야 하는 알고리즘은 **이진 검색(Binary Search)**입니다.

## 4. 요약 비교
| 구분 | 선형 검색 (Linear Search) | 이진 검색 (Binary Search) |
| :--- | :--- | :--- |
| **정렬 필수 여부** | **필요 없음** | **반드시 정렬되어야 함** |
| **데이터 접근** | 순차적 (처음부터 하나씩) | 분할 정복 (중간값 비교) |
| **효율성** | 데이터가 적을 때 유리 | 데이터가 많고 정렬된 경우 유리 |
