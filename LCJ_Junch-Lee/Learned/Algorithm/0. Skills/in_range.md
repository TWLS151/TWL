# in_range() 함수 분리의 장점 정리

## 1. 가독성(Readability) 향상

범위 조건이 코드 곳곳에 직접 들어가 있으면,

```python
if 0 <= r < N and 0 <= c < N:
```

처럼 반복되는 조건식으로 인해 코드의 핵심 로직이 묻힐 가능성 존재

이를

```python
def in_range(r, c):
    return 0 <= r < N and 0 <= c < N
```

처럼 분리하면,

```python
if in_range(r, c):
```

로 표현할 수 있어 "**무엇을 하는가**"가 더 잘 보이게 된다.

---

## 2. 중복 제거(DRY 원칙)

범위 조건이 여러 군데에서 반복되면?
- 수정이 필요할 때 모든 부분을 고쳐야 함
- 실수로 일부만 수정될 위험

함수로 분리하면:
- 범위 조건 변경 시 한 곳만 수정하면 끝
- 유지보수 용이

---

## 3. 확장성(Scalability)

처음에는 단순히 `0 <= r < N` 이었지만,

- 직사각형 격자 (행, 열 길이 다름)
- 음수 인덱스 허용 여부 변경
- 특정 셀 접근 제한 조건 추가

같은 추가 요구사항 발생 시

내부 로직을 수정하여 활용 가능

---

## 4. 테스트 용이성(Testability)

범위 체크 로직을 독립적으로 테스트할 수 있다.

```python
assert in_range(0, 0) == True
assert in_range(-1, 3) == False
```

처럼 단위 테스트가 가능

로직 검증, 디버깅 단순화

---

## 5. 추상화 수준 상승 (by GPT)

```python
if 0 <= r < N and 0 <= c < N:
```
는 구현 디테일이고,

```python
if in_range(r, c):
```
는 의미 중심 표현이다.

이 차이는 코드의 추상화 레벨을 한 단계 끌어올린다.

→ 작은 리팩토링이지만 사고 수준을 높여준다.
