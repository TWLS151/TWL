# 중위 정렬을 후위정렬로 바꾸기

이 로직의 목적은 컴퓨터는 중위 정렬을 계산하기 힘드러하기 때문이다.

그래서 내가 해야하는 로직은 첫번째 각 연산자들의 우선순위를 기록을 한다. 
일단 지금 주어진거는 딕셔너리 형태로 주어졌다. 왜냐하면 키값이랑 벨류값 이렇게 두개의 값을 지정을 할 수 있기 때문이다.
이외에 리스트, 세트는 생각을 해보면 쓸 수 없다는 것을 알 수 있다.

여기서 해야하는거는 if문과 elif, elif else이렇게 4가지 케이스를 통해서 분류를 하는 것이다.
각각을 통해서 피연산자, 연산자, 괄호의 열기 그리고 괄호닫기를 분류를 하면된다.
