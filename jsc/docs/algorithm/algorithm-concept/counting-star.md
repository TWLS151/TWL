## 1. 🎯 개념 및 필요성 (Concept)
- **한 줄 요약:** 데이터끼리 크기를 비교(vs)하는 게 아니라, 각 숫자가 몇 번 나왔는지 **'개수(Count)'를 세어서** 바구니에 담았다가 순서대로 꺼내는 방식입니다.
- **사용 목적:**
    - 일반적인 비교 정렬($O(N \log N)$)로 시간 초과가 나는 상황에서 극한의 속도가 필요할 때 사용합니다.
    - 데이터의 개수($N$)는 엄청나게 많은데, 데이터의 범위($K$, 예: 0~100점)는 좁을 때 가장 효율적입니다.

## 2. ⏱️ 복잡도 (Complexity) & 제약 조건 
> *알고리즘의 핵심은 효율성입니다. 꼭 기록하세요.*

- **시간 복잡도:** $O(N + K)$
    - $N$: 데이터의 개수, $K$: 데이터의 최댓값
    - **Best Case:** $O(N + K)$
    - **Worst Case:** $O(N + K)$ (데이터 상태와 무관하게 일정함)
- **공간 복잡도:** $O(K)$
    - 최댓값($K$) 크기만큼의 카운트 배열을 무조건 만들어야 합니다.
- **제약 조건(Key Constraints):**
    - **데이터 범위:** 최댓값이 너무 크면 메모리 낭비가 심합니다. (예: 데이터가 `[1, 10억]` 두 개뿐인데 배열을 10억 개 만들어야 함)
    - **데이터 타입:** 인덱스로 접근해야 하므로 주로 **'0 이상의 정수'**에서만 사용 가능합니다. (음수나 실수는 추가 전처리 필요)

## 3. 🧠 동작 원리 (Mechanism)
> *AI에게 요청: "이 알고리즘이 돌아가는 순서를 1, 2, 3 단계로 시각적으로 이해하기 쉽게 설명해줘"*

1. **카운트 배열 생성 (Setup):** 데이터 중 가장 큰 숫자(Max)를 찾아 `Max + 1` 크기의 빈 배열(0으로 초기화)을 생성합니다.
2. **개수 세기 (Counting):** 입력받은 데이터를 하나씩 꺼내보며, 해당 숫자와 일치하는 인덱스의 카운트를 `+1` 증가시킵니다.
3. **결과 출력 (Output):** 카운트 배열의 처음부터 끝까지 돌면서, 저장된 개수만큼 해당 인덱스(숫자)를 순서대로 출력(또는 리스트에 추가)합니다.


## 4. 💻 표준 구현 코드 (Standard Implementation)
*가장 정석적인 구현 패턴을 기록합니다. (나중에 복붙해서 쓰기 좋게)*

```python
def counting_sort(array):
    # 0. 예외 처리 (데이터가 없거나 1개일 때)
    if len(array) <= 1:
        return array

    # 1. 초기화: 데이터의 최댓값 확인 및 카운트 배열 생성
    max_val = max(array)
    count = [0] * (max_val + 1)
    
    # 2. 메인 로직: 각 숫자의 등장 횟수 세기
    for num in array:
        count[num] += 1
    
    # 3. 결과 생성: 카운트만큼 숫자를 풀어서 정렬된 리스트 생성
    sorted_array = []
    for i in range(len(count)):
        # i라는 숫자가 count[i]번 등장했으므로 반복해서 추가
        for _ in range(count[i]):
            sorted_array.append(i)
            
    return sorted_array
