## 이진 탐색 (이진 검색 알고리즘)

- 기본적인 알고리즘이므로, 반드시 숙지 필요

: 자료의 가운데에 있는 항목의 키 값과 비교하여 다음 검색의 위치를 결정하고, 검색을 계속 진행하는 방법

- 목적 키를 찾을 때 까지의 과정에서 검색 범위를 반 씩 줄여나간다는 점에서 의의가 있다

- #### 주의! : 자료는 정렬된 상태여야 한다.

---
### 과정

1. 자료의 **중앙에 있는 원소**를 고른다

2. 중앙 원소의 값과 찾고자 하는 목표 값을 비교

3. 작다면 왼쪽 반 영역에서, 크다면 오른쪽 반 영역에서 새로 검색

4. 1~3을 반복

```python
# 이진 탐색 알고리즘 (함수)

arr = [2, 4, 7, 9, 11, 19, 23]

# 1. 값을 비교
# 2. 작다 -> r을 m-1로 이동
# 2-1. 크다 -> l을 m+1로 이동
# 3. 중간값 탐색
# 4. 찾을 때 까지
# 5-1. 못찾았을 때 -> 걸러줌

def binary_search(arr, N, key): # key를 찾으면 인덱스, 실패 -1 반환

  start = 0
  end = N-1
  while start <= end:         # strat가 end를 역전하지 않는 동안 반복

    middle = (start + end)//2
    if arr[middle] == key :   # 탐색 성공
      print(middle)           # 인덱스 반환
    
    elif arr[middle] > key :  # 찾는 값보다 크다
      end = middle - 1        # 왼쪽 구간 선택

    else:                     # 찾는 값보다 작다
      start = middle + 1      # 오른쪽 구간 선택
  
  return -1
```

### >>> 핵심은 탐색 시작점, 끝 점을 `arr`의 인덱스로 둔다는 것
