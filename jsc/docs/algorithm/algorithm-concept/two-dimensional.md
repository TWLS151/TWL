## 바운더리 체크
- [핵심] 벽(경계) 체크: 이동 후 위치가 배열 범위를 벗어나지 않는지 확인
    if 0 <= nr < N and 0 <= nc < M:
        print(arr[nr][nc], end=' ')
- 경계 체크는 알고리즘 문제에서 매우 높은 빈도로 활용되므로 반드시 정리가 필요
        **왜 경계 체크가 필수일까?**
    - 파이썬은 음수 인덱스를 지원하여, `arr[-1]`과 같이 접근하면 오류 대신 리스트의 마지막 요소를 반환합니다. 델타 이동 중 계산된 좌표가 `(-1, 0)`이 되었을 때, 오류 없이 마지막 행의 첫 번째 값을 가리키게 되어 논리적 오류를 유발할 수 있습니다.
        ⇒ 따라서 의도치 않은 동작을 막기 위해 경계 체크는 필수입니다.
- 방법1
```
# next_row, next_column
nr = r + dr[i]
nc = c + dc[i]

if 0 <= nr < N and 0 <= nc < M:
    # 여기에 유효한 좌표에 대한 로직을 작성
    print(arr[nr][nc])
```

-방법2
```
for i in range(4):
    nr = r + dr[i]
    nc = c + dc[i]

    if nr < 0 or nr >= N or nc < 0 or nc >= M:
        continue

    # 이 아래는 모두 유효한 좌표임이 보장됨
    print(arr[nr][nc])
```
