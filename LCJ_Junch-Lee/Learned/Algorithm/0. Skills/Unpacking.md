# `list[(tuple)]` 구조에서의 효과적인 언패킹

참고 문제 : `SWEA - 1258. 행렬 찾기`

살펴볼 구조는 다음과 같다.

```python
matrics = [(r1, c1), (r2, c2), (r3, c3)]
```
리스트 안에 튜플이 들어있는 구조.

## 가장 효과적인 언패킹 ?

```python
for r, c in matrices:
    print(r, c)
```

동작 원리
1. 리스트를 순회
2. 각 요소(튜플)을 꺼냄
3. 자동으로 변수에 분해 (언패킹)

#### >>> 별도의 분해 작업이 필요 없음

&nbsp;

## `join`과 함께 출력 양식에 활용하기

```python 
info = " ".join(f"{r} {c}" for r, c in matrices)

print(f"#{tc} {len(matrices)} {join}")

# 출력 예 (SWEA 1258 행렬찾기)
>>> #1 3 4 2 3 2 1 1
```
