### 과정

1. 주어진 자료 중 최소값의 위치를 찾음 (`min_index`)

2. 리스트의 맨 앞에 위치한 값과 교환

- 버블 정렬과의 차이점? 
  - 계속해서 위치를 교환하는지, 교환을 한 번만 수행하는지
  - 버블 정렬의 흐름에서 인덱스 별 크기 비교 대신 **최소값 찾기**


## 선택 정렬 사고 흐름

1. 탐색할 구간 설정 `i = 0 ~ N-2` (N-1까지만 보면 되기 때문)

2. 최솟값 초기 위치 `min_idx = i`

3. i ~ N-1까지 진짜 최소값 찾기
```python
for j : i+1 ~ N-1
  if arr[min_idx] > arr[j] -> min_idx = j
```

4. 최소값을 찾았다면, 구간의 맨 앞으로!
```python
# 현재 위치를 최소값으로 변경
# 현재 위치 <-> 최소값

arr[i], arr[min_idx] = arr[min_idx], arr[i]
```


### ? : 왜 4번 과정이 저렇게 간단하게 해결되는가? 
- 전체 영역부터 생각해 본다면, 인덱스의 앞부터 차례대로 값을 탐색하기 때문

- #### (my) `start_pos`와 같은 인덱스 변수가 필요하지 않음 


- 교훈 : 알고리즘의 거시적인 영역부터 고려하는 것이 중요하겠다.
