## 탐욕 알고리즘 (Greedy)

: 여러 경우 중 하나를 결정해야 할 때 마다 그 순간에 최적이라고 생각되는 것을 선택해나가는 방식으로 진행해 최종적인 해답에 도달하는 방식 

### 순간의 선택들이 반드시 최선을 향해 가진 않는다.

: 인생의 철학을 알려주는 것 같기도...

- 일종의 '분류' 알고리즘 

- 최적해를 구하는 데 사용되는 근시안적 알고리즘

- 각 선택의 시점에서 이루어지는 결정은 지역적으로 최적이지만, 그 선택들을 계속 수집해 최종적인 해답을 만들었다고 해서, 전역적인 해답이 되지는 않음.


- 머릿 속의 생각을 검증없이 바로 구현하면 그것이 곧 Greedy 


## 과정

### My : 최선의 선택을 찾고, 검증하고, 반복해 완성한다 !

1. 해 선택 : 현재 상태에서 부분 문제의 최적 해를 구한 뒤, 이를 부분 해 집합(Solution) 에 추가한다. 


2. 실행 가능성 검사 : 새로운 부분해 ㅈ 집합이 실행 가능한지를 확인한다. 곧 문제의 제약 조건을 위반하지 않는지를 검사

3. 해 검사 : 새로운 부분 해 집합이 문제의 해가 되는지를 확인한다. 아직 전체 문제의 해가 완성되지 않았따면 (1)의 해 선택부터 다시 시작

### 예시 : 거스름돈 줄이기 

'어떻게하면 손님에게 거스름돈으로 주는 지폐와 동전의 개수를 최소한으로 줄일 수 있을까?'

거스름돈이 3백원

- 1단계 해 선택 : 가장 좋은 해를 선택

500원 선택

- 2단계 : 해 검증 - 실행 가능성

  - 500원 -> 금액 초과로 불가
  - Next : 100원 -> 가능, 3개를 지불하여 완성


 ex 2) 거스름돈이 800원이고, 동전이 100, 400, 500원짜리가 있다면?

 - 직관 : 400원 두개면 최선!

  num //= 10 # 몫(남은 자리수)을 num에 재할당
