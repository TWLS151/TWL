## 26045. 부분 수열 판별

1. 수열 $A$ 내에 수열 $B$의 원소들이 순서대로 포함되어 있는지 확인한다.
2. $B$의 원소들 사이에 다른 숫자가 있어도 되지만, 상대적인 **순서**는 반드시 유지되어야 한다.

### ver1 : 잘못된 초기 접근 (중첩 반복문) - fail

- 처음에는 $B$ 수열을 기준으로 $A$ 수열 전체를 매번 훑는 방식으로 접근을 시도했었다.
- $B$의 다음 숫자를 찾을 때마다 $A$를 처음부터 다시 뒤지는 상황이기 때문에, 순서 보장 접근이 불가능했다.
- 이 방식은, "A에 이 숫자가 들어있는가?"는 확인 가능, 하지만 "이전 숫자의 뒤에 나오는가?"의 조건은 확인 불가능했따다.

```python
T = int(input())

for tc in range(1, T + 1):
    N, M = map(int, input().split())
    arr_N = list(map(int, input().split()))     # 수열 A
    arr_M = list(map(int, input().split()))     # 수열 B
   
    for i in range(M):
        for j in range(N):
            if arr_N[j] == arr_M[i]:
                ...

    print(f'#{tc} {ans}')
```

### ver 2: 로직 개선 (Single For-If)
- $A$ 수열을 한 번만 순회하며 $B$ 수열의 인덱스(b)를 하나씩 증가시키는 방식이다.
- 순서 보장 : arr_M[0]을 찾았다면, 그 숫자보다 뒤에 있는 위치에서 arr_M[1]을 찾아야 하는 것이 핵심!
- 경계값 검사: 리스트 인덱스를 변수로 다룰 때는 항상 b < M과 같은 조건을 먼저 체크하여 IndexError를 방지해야 한다.

```python
T = int(input())

for tc in range(1, T + 1):
    N, M = map(int, input().split())
    arr_N = list(map(int, input().split()))
    arr_M = list(map(int, input().split()))

    b = 0  # arr_M의 인덱스를 추적

    for x in arr_N:
        # b < M 조건을 추가하여 IndexError를 방지함
        if b < M and x == arr_M[b]:
            b += 1

    if b == M:
        ans = 'YES'
    else:
        ans = 'NO'        

    print(f'#{tc} {ans}')
```

### ver 3: AI-refactoring (최적화 및 가독성)

- 조기 종료(break) 로직 사용하여 최적화, 명확한 변수명으로 수정하여 가독성있게 한다.

```python
    T = int(line)

    for tc in range(1, T + 1):
        N, M = map(int, input().split())
        arr_N = list(map(int, input().split()))
        arr_M = list(map(int, input().split()))

        # 2. 명확한 변수명: target_idx (B 수열에서 지금 찾아야 할 위치)
        target_idx = 0 

        # 3. 효율성 개선: O(N) 단일 루프 및 조기 종료 적용
        for num in arr_N:
            if target_idx < M and num == arr_M[target_idx]:
                target_idx += 1
            
            # 목표한 숫자를 다 찾았다면 더 이상 루프를 돌 필요 없음
            if target_idx == M:
                break

        # 4. 삼항 연산자를 사용한 깔끔한 출력 (참일 때의 값 if 조건식 else 거짓일 때의 값)
        ans = 'YES' if target_idx == M else 'NO'
        print(f'#{tc} {ans}')
```
