# SQL 명령어의 종류

|종류|정의|
|---|---|
|데이터 정의어(DDL)|스키마 설정 혹은 수정하는 작업(create)|
|데이터 조작어(DML)|데이터 베이스 내의 인스턴스를 다루는 작업(select 등)|
|데이터 제어어(DCL)|데이터 제어어(grant,revoke)|
|트랙잭션 제어어(TCL)|트랜잭션 제어를 위한... 일관성 유지를 위한 ACID유지를 위한... 커밋 롤백등| 

# SQL연산자의 우선 순위
|우선순위|연산자 종류|연산자|
|---|---|---|
|1|괄호|()|
|2|산술 연산자|*, /|
|3|산술 연산자|+,-|
|4|SQL (결합) 연산자|\|\||
|5|비교 연산자|=,!=,<>,>,>=,<,<=,^=|
|6|SQL (조건) 연산자|BETWEEN,LIKE,IN,NOT IN, IS NULL, IS NOT NULL| 
|7|논리 연산자|NOT|
|8|논리 연산자|AND|
|9|논리 연산자|OR|
