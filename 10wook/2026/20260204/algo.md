## 누적합
누적합에 대해서 공부했습니다.
일단 1차원 누적합 개념은 이해를 하고 있었는데,
2차원 누적합 그래프를 빠르게 만들고,  빠르게 이용하면 좋은 결과를 쉽고 빠르게 얻을 수 있구나 싶어서 좋았습니다.


일단 두 단계로 정리하자면.....


### 1. 행열 빠르게 만들기
2차원 누적합의 배열은 다음 개념을 따라서 작동합니다.
크기가 $N*N$ 인 기본 배열의 경우  => 이를 행열 $A$라 한다

$(N+1)*(N+1)$  크기의 행열을 만들고, 이를 $P$ 라 한다. (크기는 이렇지만 -1 행과 열이 0으로 채워져있다고 생각하면 좋다.)



$P$의 경우 첫번째 행과 열에는 모두 0이 들어간다.

이후부터 다음 규칙에 따라서 값을 추가합니다.


$P_{a b} = A_{a-1 b-1} + P_{a b-1} + P_{a-1 b} -  P_{a-1 b-1}$

이 방식을 활용하면 빠르게 적은 시간 복잡도로 누적합 행렬을 만들 수 있습니다.

원본: 
| i\j | 0 | 1 | 2 |
| --- | - | - | - |
| 0   | 1 | 2 | 3 |
| 1   | 4 | 5 | 6 |
| 2   | 7 | 8 | 9 |
결론
| i\j | 0 | 1  | 2  | 3  |
| --- | - | -- | -- | -- |
| 0   | 0 | 0  | 0  | 0  |
| 1   | 0 | 1  | 3  | 6  |
| 2   | 0 | 5  | 12 | 21 |
| 3   | 0 | 12 | 27 | 45 |

### 2. 여기까지 다 더 한거에서 내가 필요없는 부분을 잘라내며 원하는 모양만들기

$A_{22} + A_{23} + A_{32} + A_{33}  = ​P_{44}−P_{24}−P_{42}+P_{22}$​


이 수식으로 계산하면 됩니다.
## 델타
상·하·좌·우 델타 (4방향)
```python
dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]
```

위 → (r-1, c)

아래 → (r+1, c)

왼쪽 → (r, c-1)

오른쪽 → (r, c+1)

델타 탐색 기본 형태
```python
for d in range(4):
    nr = r + dr[d]
    nc = c + dc[d]

    if 0 <= nr < N and 0 <= nc < M:
        # (nr, nc)는 유효한 위치
        pass
```
