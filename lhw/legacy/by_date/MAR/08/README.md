### Java의 Method 개념을 학습했습니다.

[1] Method of Java is Function in Python.  
 파이썬의 함수 개념을 이미 알고 있어서 기본적인 개념을 익히는 데는 오래 걸리지 않았습니다. 조금 다른 점이라고 하면 Overloading이 있었습니다.

[2] Overloading.  
 오버로딩은 같은 기능을 수행하는 메서드를 타입에 따라 여러 개로 나누는 작업을 의미합니다. `덧셈` 기능을 수행하는 메서드 `add`를 `int`간의 덧셈, `int`와 `double`간의 덧셈, 또는 `double`과 `double` 사이의 덧셈 등 여러가지 타입에 맞추어 기능을 수행할 수 있도록 합니다.
