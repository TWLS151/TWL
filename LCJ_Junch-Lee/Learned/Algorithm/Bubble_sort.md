내림차 or 오름차로 재배열하는 알고리즘

## 버블 정렬

: 인접한 두 개의 원소를 비교하며 자리를 계속 교환하는 방식

### 과정

1. 첫 번째부터 인접 원소끼리 계속해서 자리를 교환
2. 한 단계가 끝나면 가장 큰 원소가 마지막 자리로 정렬

- 시간 복잡도 : O(n**2)



## 핵심 요소

- 끝 값 위치 인덱스 : i
- 인접값 비교 인덱스 : j

### 슈도 코드

```python
for i in range(N-1, 1, -1):

  for j in range(i): # 왜 i일까?

    if arr[j] > arr[j+1]:

      arr[j] = arr[j+1]
      arr[j+1] = arr[j]
```


## 버블 정렬에서의 핵심

### 1. 범위 설정 및 변화 

- 외부 / 내부 반복의 문제 : 
#### 각각 반복문이 맡은 역할은 무엇인가? 
#### 역할에 따라 범위를 어떻게 설정할 것인가? 의 문제. 

- 각 문제 별로 변화하는 범위를 range() 등으로 잘 컨트롤 해줄 수 있나?

  - ex. 버블정렬 : 1 step마다 맨 끝 자리가 결정되므로, 외부 범위 또한 계속 줄어들어야 함 


- 알고리즘 공부 초기 단계에서는, 각각의 시나리오를 직접 쓰거나 그려가며 흐름을 파악하는 것이 Best!
