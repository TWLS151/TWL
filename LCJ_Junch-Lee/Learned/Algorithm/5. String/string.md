- 인덱싱, 슬라이싱을 통한 접근이 가능

- 글자 단위 수정은 불가! 문자열은 `immutable`한 자료형


## ABCD 패턴 찾기

```python

N = int(input())
text = [input() for _ in range(N)]
pat = ['AB', 'CD']

for i in range(N-1): # N-2 인덱스까지만 탐색하면 됨
  for j in range(N-1):
    
    # 패턴이 맞는지 검사하는 방법
    # 1. 패턴을 미리 저장해두고 검사
    
    if text[i][j] + text[i][j+1] != pat[0] or text[i+1][j]+text[i+1][j+1] != pat[1]:

```
