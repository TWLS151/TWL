## 카운팅 정렬


: 항목들의 순서를 결정하기 위해 집합에 각 항목이 몇 개씩 있는지 **세는 작업**을 하여 선형 시간에 정렬하는 효율적인 방식 

### 제한 사항 : 조건부 사용 

- 정수 or 정수로 표현할 수 있는 자료에 대해서만 가능
  - 각 항목의 발생 횟수를 기록하기 위해 정수 항목으로 인덱스되는 카운트들의 배열을 사용하기 때문? 

  - my : 


- 카운트들을 위한 충분한 공간을 할당하려면 집합 내의 가장 큰 정수를 알아야 함


### 단계별 접근 

- 1단계 : DATA에서 각 항목들을 카운트, 정수 항목들로 직접 인덱스되는 카운트 배열 COUNTS에 저장

  - my : 각 숫자가 몇 번 나오는지 파악
  
  - ? : COUNTS의 길이는 등장하는 숫자열의 가장 큰 숫자 만큼의 길이가 필요 ! 

  - 모든 DATA에 대해 각 하나씩 개수를 세주려면? 

---

```python
# COUNTS의 길이가 어떻게 되어야 할까? 
COUNTS = [0]*(max_v + 1)

# 모든 DATA를 다루려면? 

for idx in range(N): # N = 숫자열의 길이

  # DATA의 값을 COUNTS로 어떻게 이어갈 것인가? 
  # COUNTS의 각 인덱스 자리값은 곧
  # 그 숫자의 등장 횟수 ! 
  COUNTS[DATA[idx]] += 1

  # +@ 딕셔너리 카운팅에 대해 공부하자

```
---

### 핵심 : 누적합 

- 2단계 : 정렬된 집합에서 각 항목의 앞에 위치할 항목의 개수를 반영하기 위해 COUNTS의 원소를 조정한다 


  - my : 누적 개수를 파악한다! 내 앞의 숫자까지의 누적합 다음이 곧 해당하는 숫자가 들어가야할 위치 

  - 해당 자리까지의 누적합 : 이전까지의 누적합 + 해당 숫자의 개수 

```python
COUNTS[i] = COUNTS[i-1] + COUNTS[i]
```

---
- 3단계 : `DATA`의 마지막 원소 `1`의 발생횟수 `COUNTS[1]`을 감소시키고 그 값을 그대로 인덱스로 반영해 `TEMP`에 삽입

  - 기록할 배열 `TEMP`이 필요 !


 - COUNT[DATA[6]]의 의미? 
-> DATA 숫자열의 7번째 인덱스에 있는 숫자 이하의 값의 개수가 COUNT[DATA[6]]에 저장되어 있으니, 즉 해당 숫자를 포함해 총 COUNT[DATA[6]]개 있으니까 이 숫자가 들어갈 인덱스는 COUNT[DATA[6]]-1이 된다 ! 


 -  0과 1이 총 4개가 있는데, 그 중 `DATA`의 마지막 값인 1은 적어도 하나가 있으니까 1을 4번째 자리에 먼저 할당!


 ```python 

for j in range(N-1, -1, -1): # J =5일때
  COUNTS[DATA[j]] -= 1 
  # DATA[j] = 2, counts의 2번째 인덱스가 5->4
  

  # 직전에 계산한 COUNTS[DATA[j]]-1의 값이 그대로 TEMP의 인덱스가 됨 

  TEMP[COUNTS[DATA[j]]] = DATA[j]

 ```
