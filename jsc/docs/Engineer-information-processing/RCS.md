# RCS (Revision Control System)

## 정의
소프트웨어 개발 시 파일의 **변경 내용을 추적**하고, 여러 사용자가 **동시에 소스를 수정하는 것을 방지**하며, 다른 방향으로 진행된 **개발 결과를 합치기** 위해 사용하는 소프트웨어 버전 관리 도구입니다.

## 주요 특징
- **파일 잠금(Locking):** 한 사용자가 파일을 수정 중일 때 다른 사용자가 수정하지 못하도록 제한하여 충돌을 방지합니다.
- **버전 추적:** 파일의 수정 이력을 관리하여 특정 시점으로 되돌리거나 변경 사항을 확인할 수 있습니다.
- **로컬 관리:** 주로 단일 호스트 내에서 파일의 리비전을 관리하는 초기 형태의 버전 관리 시스템입니다.
