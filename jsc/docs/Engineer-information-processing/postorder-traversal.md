## 트리 순회 요약: 후위 순회 (Postorder Traversal)

### 1. 후위 순회 정의
후위 순회는 트리 구조에서 자식 노드를 모두 방문한 뒤, 마지막에 자기 자신(루트)을 방문하는 방식입니다.
- **순서:** 왼쪽 서브트리 → 오른쪽 서브트리 → **현재 노드 (Root)**

### 2. 문제 풀이 (이미지 기준)
제시된 트리 구조에서 방문 순서는 다음과 같습니다.

1. **왼쪽 서브트리 처리**: `d` (왼쪽 끝) → `b` (부모)
2. **오른쪽 서브트리 처리**: 
   - `e` 하위 노드 먼저: `g` (왼쪽) → `h` (오른쪽) → `e` (부모)
   - `c` 하위 노드 마무리: `f` (오른쪽 자식) → `c` (부모)
3. **루트 노드 방문**: `a`

**최종 결과:** `d` → `b` → `g` → `h` → `e` → `f` → `c` → `a`

### 3. 시험 대비 팁
- **후위 순회(Postorder)**: 최상위 루트 노드가 결과값의 **가장 마지막**에 위치합니다.
- **전위 순회(Preorder)**: 루트가 가장 앞에 위치합니다.
- **중위 순회(Inorder)**: 왼쪽 → 루트 → 오른쪽 순서로 진행됩니다.
