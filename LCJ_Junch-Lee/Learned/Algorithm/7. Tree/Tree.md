# Tree (비선형 자료구조)

정의

한 개 이상의 노드로 이루어진 유한 집합이며, 아래의 조건을 만족하는 자료구조
- 노드 중 최상위 노드를 루트(`root`)라 한다.
- 나머지 노드들은 `n(>=0)`개의 부분집합 `T1`, ..., `TN`으로 분리됨

- #### 이 `T1`, ..., `TN`은 각각 하나의 트리가 되며(재귀적 정의), 부트리(`subtree`)라 정의


## 용어 정리

1. 루트 노드 : 트리의 시작 노드


2. 형제 노드 : 같은 부모 노드의 자식 노드


3. 조상 노드 : 간선을 따라 루트 노드까지 이동하는 경로에 있는 모든 노드

- `K`의 조상 노드 : `F`, `B`, `A`


4. 서브 트리 : 부모 노드와 연결된 간선을 끊었을 때 생성되는 트리


5. 자손 노드 : 서브 트리에 있는 하위 레벨의 노드들


6. 노드의 차수 : 노드에 연결된 자식 노드의 수

7. 트리의 차수 : 트리에 있는 노드의 차수 중에서 가장 큰 값

8. 단말 노드 (리프 노드)

- 차수가 0인 노드. 즉, 자식 노드가 없는 노드

9. 노드의 높이 : 루트에서 노드에 이르는 간선 수 (노드의 레벨)

10. 트리의 높이 : 트리의 노드 높이 중 가장 큰 값. 최대 레벨


> 1 : N 상황에서는 트리보단 그래프가 선호되지만,
> 특정한 상황에서 트리가 강점을 발휘할 수 있다.


## 이진 트리

### 모든 노드들이 2개 이내의 서브(자식) 트리를 갖는 특별한 형태의 트리

- 우리가 다루는 대부분의 트리 형태는 이진 트리!

### 이진 트리의 속성

- 레벨(높이) `i`에서의 노드의 최대 개수는 `2**i`개 
- 높이가 `h`인 이진 트리가 가질 수 있는 노드의 최소 개수는 (`h+1`)개, 최대 개수는 `2**(h+1)-1`개


### 포화 이진 트리 (`Full Binary Tree`)

- 모든 레벨의 노드가 **포화상태**로 차있는 이진 트리
- `N = 3`일 때,, 최대 노드의 개수인 `2**(h+1) - 1`개.

### 완전 이진 트리 
- 포화 이진 트리의 노드 번호 1번부터 N번까지 빈 자리가 없는 이진 트리


### 편향 이진 트리 (`Skewed Binary Tree`)

: 높이가 `h`에 대한 최소 개수의 노드를 가지면서 한쪽 방향의 자식 노드만을 가진 이진 트리


## 트리의 표현 (저장) 방법

### 1. 배열을 이용한 이진 트리의 표현

- 이진 트리에 각 노드의 번호를 부여
- 루트의 번호를 1번으로 부여
- 레벨 `n`에 있는 노드에 대하여 왼쪽부터 오른쪽으로 `2**n`부터 `2**(n+1) -1`까지 번호를 차례로 부여


### 2. 노드 번호의 성질

- 노드 번호가 `i`인 노드의 부모 노드 번호?
- `i//2`

- 노드 번호가 `i`인 노드의 왼쪽 자식 노드 번호? 
- `i * 2`
- 오른쪽은? `2 * i + 1`

- 레벨(높이) `n`의 시작 노드 번호는? `2**n`

 
 ### 3. 배열을 이용한 이진 트리의 표현

- 노드 번호를 배열의 인덱스로 사용
- 높이가 `h`인 이진 트리를 위한 배열의 크기는?
  - 레벨 `i`의 최대 노드 수는 `2**i`
  - 따라서 `2**(h+1) -1`
