## 선형 자료구조 (Linear)

: 데이터가 일렬로 나열되어 서로 1:1 관계를 가지는 자료구조

- ex. 배열, 스택, 큐


### 구성요소

- `push` : 데이터를 맨 위에 삽입(저장)함

  - `list.append(item)`

- `pop` : stack의 맨 위 요소를 꺼내고 (삭제) 반환

- `peak` : 스택의 맨 위 데이터를 반환, 꺼내지는 않음

  - `list[-1]` (접근)

- `is_empty` : 스택이 비어있는지 확인 

  - `len(list) == 0`

### Stack Overflow & Underflow

- `Overflow` : 꽉 찬 스택에 데이터를 더 넣으려 할 때
- `Underflow` : 비어있는 스택에서 데이터를 꺼내려 할 때
