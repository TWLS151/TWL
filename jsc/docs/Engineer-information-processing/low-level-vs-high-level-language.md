# [TIL] 기계어, 어셈블리어, 그리고 고급 언어의 이해

정보처리기사 및 개발 기초 지식 정리를 위한 프로그래밍 언어의 단계별 특징 정리

## 1. 기계어 (Machine Language)
컴퓨터의 CPU가 직접 해석하고 실행할 수 있는 가장 낮은 단계의 언어입니다.
- **형태:** `0`과 `1`로 이루어진 이진수 데이터 (예: `01010110`)
- **특징:** - 컴퓨터가 즉각 이해할 수 있는 유일한 언어입니다.
    - 사람이 직접 읽고 쓰기에는 매우 어렵고 에러 발생 확률이 높습니다.

## 2. 어셈블리어 (Assembly Language)
기계어의 이진수 명령어를 사람이 알아보기 쉬운 **기호(Mnemonic)**로 1:1 대응시킨 언어입니다.
- **형태:** `ADD`, `SUB`, `MOV`, `PUSH` 같은 짧은 단어와 메모리 주소의 조합
- **특징:**
    - 기계어와 가장 가까운 '저급 언어'입니다.
    - 하드웨어(CPU, 메모리)를 직접 제어할 때 사용합니다.
    - 기계어로 번역해주는 **어셈블러(Assembler)**가 필요합니다.

## 3. 고급 언어 (High-Level Language)
인간의 언어(주로 영어 문법)와 유사하게 만들어진 사용자 친화적인 언어입니다.
- **종류:** Python, Java, C, JavaScript 등
- **특징:**
    - 하드웨어에 대한 깊은 지식 없이도 로직에 집중하여 개발 가능합니다.
    - 컴퓨터가 이해할 수 있도록 **컴파일러(Compiler)**나 **인터프리터(Interpreter)**가 기계어로 번역해줍니다.

## 🔍 핵심 비교 요약

| 구분 | 기계어 | 어셈블리어 | 고급 언어 (Python 등) |
| :--- | :--- | :--- | :--- |
| **언어 수준** | 저급 언어 (Low-level) | 저급 언어 (Low-level) | 고급 언어 (High-level) |
| **가독성** | 매우 낮음 (0과 1) | 보통 (기호 형태) | 매우 높음 (영어 문장 비슷) |
| **기계 대응** | 1:1 직접 실행 | 기계어와 1:1 대응 | 추상화된 명령 (1:N 대응) |
| **주요 용도** | CPU 실행 모드 | 하드웨어 제어, 성능 최적화 | 웹/앱 서비스, AI, 알고리즘 |

## 💡 기억할 포인트 (정보처리기사 대비)
1. **IDE의 기능 중 '컴파일(Compile)'**은 우리가 작성한 **고급 언어를 저급 언어(기계어)**로 변환하는 과정을 말하며, 그 반대(저급→고급)는 틀린 설명입니다.
2. 기계어와 어셈블리어는 둘 다 하드웨어에 가까운 **저급 언어**군에 속합니다.
