# 델타 함수 (Delta)
오늘은 델타 함수가 무엇인지에 대해서 알아보도록하겠습니다.


사실 다들 계속 그냥 똑같은 거라고 설명해서 이해를 못했는데 어제 유림양과 코드를 뜯어보다가 저격총 맞은 것 처럼 깨달아버렸습니다.

진짜 똑같은거라는 사실을 말입니다....


그리고 제 방식은 원래 제 세계에서 저한테만 쉬운 내용이었고..
한번 델타 함수의 개념을 이해하고 나니까 이쪽이 이해가 훨씬 쉽고, 순회하며 각 자리를 조회하기가 훨씬 쉽다는 사실을 이해해버렸습니다.


일단 기존의 한영욱이 어떻게 코드를 작성했는지 보여드리겠습니다.
```python
def move(x:int,y:int,dir:int):
    #0-> 오른쪽 이동
    #1-> 아래쪽 이동
    #2-> 왼쪽 이동
    #3-> 위쪽 이동
    if dir == 0:
        return x,y+1
    if dir == 1:
        return x+1,y
    if dir == 2:
        return x,y-1
    if dir == 3:
        return x-1,y
```

귀찮고, 활용할 때마다 분기를 확인하고 처리해주어야 한다는 문제가 있습니다.

하지만 일단 이제가 지금까지 이해한 바의 델타 함수는 이렇게 생겨먹었다
```python
def delta_move(x,y,dir):
    # 각 방향 이동시 추가해야하는 값을 미리 할당한다.
    # 상하좌우 순서로 이동을 기록해둔다
    # 0 => 상, 1 =>하, 2=>좌, 3=>우 
    dx = [-1,1,0,0]
    dy = [0,0,-1,1]
    return x+dx[dir], y+dy[dir]
```
코드를 이렇게 보면 개념은 지정된 방향에 따른 움직임을 반영한 값을 출력하는 함수임을 알 수 있다.


다만 그런 개념을 델타 함수라고한다면 나도 델타 함수를 구현을 하긴했다고 생각하긴한다. 다만 그게 무식하고 바보 같은 방식이었던 반면, 이렇게 리스트에 움직임을 미리할당하고 사용하면 조금 더 우아하고 정리가 된 개념이라는 생각이든다.



한 친구는 이걸 내가 쓰던 기존에 쓰던 방식,, 그리고 델타로 우아하게 표현방식을 두고, 전여친과 치열하게 싸웠었다고 한다.
