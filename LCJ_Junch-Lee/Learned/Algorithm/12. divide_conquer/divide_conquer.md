## 2. 퀵 정렬 


> 기준값을 중심으로 배열을 두 개로 `Partitioning`하고, 각각을 정렬해 전체 배열을 정렬하는 방식

1. 작업 영역을 지정

2. Pivot 결정

3. Pivot을 중심으로 
- Left : 작은 값 배치
- Right : 큰 값 배치 

4. 더 이상 나눌 값이 없다면? 종료

### Hoare-Partition

- #### Pivot = arr[0]을 사용

- ### 효율적인 값 : median
- 그러나, 바로 찾아낼 수는 없음
    - 초기 배열의 0, -1, 중앙 인덱스 값 중 중간값을 사용

- ### `i`, `j` 인덱스의 역할

    - `i` : Pivot보다 큰 값을 찾는 포인터 (left)
    - `j` : Pivot보다 작은 값을 찾는 포인터 (right)

    - `if i < j` : `i`와 `j`를 교환
    - `if j < i` : `j`의 위치가 곧 Pivot의 위치
        - why? j < i라는 것은, Pivot을 중심으로 작은값, 큰 값


## Lomuto Partition

- Pivot 기반은 동일하나, `i`, `j` 모두 왼쪽부터


### 퀵 정렬의 시간복잡도

- `Pivot`의 설정에 따라서 달라진다. (데이터의 분포에 따라)
- 평균 : `O(NlogN)`
    - 실제 연산 시간이 효율적
    - 데이터가 많을 수록 효율적

- 최악 : `O(N^2)`
    - 반대로 정렬될 수록 최악의 시간 복잡도 
        - 요소 `N`개를 하나씩 비교해야 함
